内分泌系统与月经调节

#

8.28课堂 · 从关键器官建立概念地图

打开本篇笔记 PDF

核心提要

  • 本段用手绘示意图介绍下丘脑、垂体、甲状腺、肾上腺与卵巢，并引出压力和月经的关系。
  • 可把主线整理为：感知状态、传递激素信号、靶器官反应，以及反馈调节；不要把不同调节轴混为一条路。
  • 原文的固定受孕日期与“安全期”说法不能用于避孕，月经日历不能保证排卵日期。R1

调节层次

  • 下丘脑与垂体参与内分泌调控。
  • 甲状腺、肾上腺和卵巢分别承担不同功能。
  • 并非所有激素都由垂体直接分泌。

两条课堂主线

  • 压力讨论围绕下丘脑-垂体-肾上腺轴。
  • 月经讨论围绕下丘脑-垂体-卵巢轴。
  • 两者可以相互影响，但不能画成同一条通路。

原图缺失的限制

  • 原文多次说“这个地方”，依赖现场手绘。
  • “中绕”“终老”等按语境整理为中脑。
  • 不根据残缺文字补造解剖图或精确连接。

器官名称与阅读重点

名称本段讨论方向需要区分
下丘脑、垂体调节信号与反馈感知、释放与合成不是一回事

02

月经记录、压力与甲状腺

#

用真实时间线理解变化，避免单一病因解释

打开本篇笔记 PDF

核心提要

  • 本段讨论月经推迟、经量变化、压力、多囊相关表现和甲状腺问题。
  • 多数成人的周期可在21-35天之间，28天是常见平均值，不是人人必须达到的标准。R2
  • 周期改变值得记录，但不能凭一次推迟、爱吃甜食或情绪波动就诊断多囊或桥本病。

怎样记录月经

  • 记录每次开始日期、间隔和出血天数。
  • 同时记经量变化、疼痛及对生活的影响。
  • 与本人一贯模式比较，不只看应用预测。

原文中的多囊话题

  • 讲者提到经期稀发、体毛变化与体重改变。
  • 这些线索可以帮助描述问题。
  • 诊断还需结合其他表现、检查并排除其他病因。R3

甲状腺话题

  • 原文将代谢、情绪和月经变化联系起来。
  • 桥本病属于自身免疫性甲状腺疾病。R4
  • 不能把它直接解释成“甲亢和甲减同时发生”。

从现象走向更具体的问题

现象需要补充的记录不能直接推出
周期越来越长连续数月的实际间隔必然是安全感不足
经量变化持续时间、出血量和伴随症状仅凭颜色判断激素水平
多毛、痤疮等出现时间及相关检查吃甜食就一定患多囊
情绪、体重变化作息、用药与甲状腺资料颈部训练能治好甲状腺病
  1. 记录周期从出血首日算起
  2. 观察趋势比较个人既往模式
  3. 汇总伴随表现经量、疼痛、体重等
  4. 结合检查分析可能原因

保留的课堂重点

压力、生活方式和身体状态可以一起讨论，但记录要具体。讲者建议关注周期变化的思路有用，统一要求“28天且血量多”则不成立。

疾病名与原文边界

本页沿用原文的“多囊卵巢综合征”名称便于对应。关于戒面、练颈椎即可改善内分泌的说法未获本材料证实，不作为治疗结论。

原笔记核对来源：[R2] NHS · 月经周期与生育力；[R3] WHO · 多囊卵巢综合征；[R4] NIDDK · 桥本病

检查结果与课堂应用边界

#

月经、备孕和个人体检经验需要分别判断

打开本篇笔记 PDF

核心提要

  • 本段围绕周期过短、子宫发育、内膜厚度及备孕问题展开，后半是讲者的肾功能与工作压力经历。
  • 检查结果必须联系病史、周期时点及具体项目，不能用一个数字或一句“有月经”排除问题。
  • 讲者明确表示不能凭转述远程诊断；后续建议也应遵守同样的边界。

甲状腺检查问答

  • 原文提到TSH、T3、T4及甲状腺相关抗体。
  • 项目选择取决于具体疑问和既往结果。
  • 不能把所有抗体超过同一个数字都判为异常。

备孕问题

  • 涉及子宫结构、反复妊娠停止和内膜厚度。
  • 缺少病历及检查时点，无法建立因果关系。
  • 这些问题不能用课堂反射训练替代评估。

个人肾功能经历

  • 讲者讲述eGFR检查及生活方式变化。
  • 数值、时间及先天结构描述存在转写疑点。
  • 个人变化不能证明高强度训练逆转肾病。

正确使用检查信息

材料需要看什么避免的推论
甲状腺抗体检验项目、单位、参考范围统一以10或100作诊断线
子宫内膜厚度周期时点、症状和超声报告有月经就一定没有问题
反复胎停经历完整病史与专科检查先天结构差异都无关紧要
肾功能数值重复结果及其他肾损伤指标一次eGFR即可定性不可逆衰竭
  1. 收集原报告不只听一个数值
  2. 核对背景时点、症状与用药
  3. 说明局限哪些信息仍缺失
  4. 确定下一步由相应专业评估

生活管理的可用部分

原文后半强调减少持续工作、设定休息边界，以及记录体检变化。这些可以作为自我管理话题，但不是特定疾病的疗效证据。

原文待核对

“140减年龄就是正常肾功能”“先天异常都不重要”“有月经就没有子宫问题”等概括不采用。严重或反复的生殖健康问题不能以课堂经验作结论。

#

把内分泌、肌肉紧张与发育话题分层理解

打开本篇笔记 PDF

核心提要

  • 本段回应学习压力、卵巢切除、肌肉紧张和孕期活动等问题，继续回顾内分泌反馈。
  • 工作与休息需要安排，但不能由一次学习疲劳直接预测经量或激素变化。
  • 肌肉紧张、面部动作困难及孕期运动属于不同问题，不能统一归因于中脑或安全感。

压力与休息

  • 讲者分享连续讲课与课后停止工作的习惯。
  • 可保留的重点是给恢复留出时间。
  • 不把讲者长时间不进食的习惯当通用方案。

激素相关问答

  • 学员询问子宫、卵巢手术后的反馈变化。
  • 原文提到激素治疗及骨健康。
  • 具体是否需要治疗，不能仅按年龄或绝经判断。

肌肉和发育

  • 课堂把紧张、肌肉收缩与神经活动作联系。
  • 还讨论面部动作及婴儿早期反射。
  • 不能由僵硬或不熟悉动作定位脑区异常。

把不同层次的问题分开

话题本段关注不能替代
学习和工作负荷、休息及主观紧张月经改变的临床评估
生殖器官手术激素反馈与后续状态具体手术及用药决策

孕期活动运动场景与身体体验个体化产科运动建议
  1. 明确问题层次生活、功能或疾病
  2. 记录具体表现避免笼统标签
  3. 核对机制比喻不当因果
  4. 按需要评估不套用同一个方案

孕期部分的整理

原文比较跑步机和户外活动，并推测胎儿前庭发育。该推测不足以断言跑步机无效、力量训练剥夺胎儿供血，或某条路线决定单侧发育。

感觉输入、疼痛与闸门理论

#

区分已有理论、讲者假设和个案体验

打开本篇笔记 PDF

核心提要

  • 本段从孕期环境转入本体感觉、触觉与痛温觉，并用闸门理论解释课堂手法。
  • 讲者明确承认部分解释属于自己的经验与研究假设，笔记保留这一证据层级。
  • 疼痛是真实的个人体验，不能用“幻觉”否认疼痛，也不能把创伤或家庭暴力归为颈部问题。R5

感觉的不同来源

  • 原文把本体感觉、触觉与慢性痛温觉作对比。
  • 涉及较粗感觉纤维与C纤维的通俗描述。
  • 神经不能简单分成“好纤维”和“坏纤维”。

理论与假设

  • 闸门理论是讨论疼痛调节的理论框架。
  • “C纤维压住本体感觉”是讲者的延伸解释。
  • 不能由这一说法证明所有症状同源。

课堂应用

  • 讲者介绍枕下区域手法及配合产品。
  • 随后征集同时有情绪和身体不适的个案。
  • 产品、手法与效果之间尚无独立证据。

论述中的三个证据层次

层次本段材料合理的写法
理论概念感觉输入与疼痛调节说明概念，避免无限外推
讲者假设C纤维与身体定位的关系明确标为待验证解释
产品与手法自述枕下操作及膏剂用途不作为独立疗效证明
个人经历疼痛、自我评价和家庭关系尊重叙述，不替他人定性
  1. 分清感觉类型身体位置与不适
  2. 识别解释层级理论、假设、经验
  3. 记录实际反馈不预设一定有效
  4. 保留其他原因不作单一归因

整理后的核心理解

大脑参与感觉和疼痛处理，不等于症状是编造的。身体体验、情绪、既往受伤和生活处境可以共同讨论，不应互相替代。

家庭经历的边界

原文含否定受伤经历及以个人遭遇要求他人和解的说法，笔记不采纳。颈部手法不能用来否认虐待、强迫原谅或证明家庭关系已被解决。

原笔记核对来源：[R5] IASP · 疼痛定义

情绪与身体个案的基线记录

#

先分清主诉、具体事件与评分对象

打开本篇笔记 PDF

核心提要

  • 本段从多位学员中选出一位个案，记录家庭经历、自我评价、疼痛及身体感受。
  • 课堂希望用具体事件和分项评分作前后比较；情绪、身体定位与自信不能混成一个总分。
  • 所述家庭伤害应作为当事人经历受到尊重，不能倒推出分娩方式或颈部功能是唯一原因。

具体事件

  • 参与者讲述童年患病时受到责骂等经历。
  • 其对母亲的不满约8分，具体强度表述有变化。
  • 复测需针对同一事件，不强迫重复痛苦细节。

身体主诉

  • 左侧偏头痛、肩颈不适及右大腿外侧酸感。
  • 部分不适口头记录约3分，需分项保存。
  • 胃部等描述存在混乱，不补设精确诊断。

主观感受

  • 闭眼时身体轮廓模糊，清晰度约2分。
  • 自我评价与医美后的自信约4-5分。
  • 这些属于现场自评，并非标准化量表。

个案基线应分别记录

指标本段口述比较时注意
具体事件的不满约8分，后续描述有波动同一事件、同一问法
偏头痛等身体不适部分约3分部位与评分对象分别写
身体感受清晰度约2分，轮廓模糊注明闭眼与姿势条件
对自己的信心约4-5分不要与身体清晰度混用
  1. 征得参与意愿允许不回答或停止
  2. 明确主诉由本人选择重点
  3. 分项记录基线情绪、感觉、疼痛
  4. 留待同条件复测7号继续记录

可保留的方法

具体问题比笼统问“好了吗”更容易比较。主诉、事件和评分对象要提前说明，参与者自己的话与讲者推断分开记录。

不采用的解释

“母亲不爱孩子必因生产不顺”“挑剔、洁癖或择偶偏好说明上颈椎有病”等缺少依据。对创伤的讨论应尊重自主选择，不以现场施压制造疗效。

  • 触觉主要提供皮肤接触等信息。
  • 本体感觉帮助感知肢体位置和运动。
  • 课堂的训练先后顺序属于其教学安排。

觉醒与脑电

概念关注的信息不要等同于

本体感觉位置、运动及相关感觉输入单纯皮肤被触摸
α节律一种脑电活动特征人人必经且唯一的入睡开关
睡眠调节脑区、节律和睡眠需要等颈部位置感一项指标

  2. 联系动作任务准确性不只是力量
  3. 理解觉醒系统多个结构共同参与
  4. 回到睡眠记录时间、觉醒与白天状态

表现具体问法不能用什么替代
尿急或尿频多突然、多频繁、是否影响生活不能只问此刻想不想尿
漏尿何时漏、是否伴急迫感或活动尿意减轻不代表漏尿减少
排尿困难或不尽感能否启动、尿流、是否排空不能用尿意低推断已排净
正常膀胱充盈饮水、上次排尿与当前感觉有尿意并不自动等于疾病
  1. 描述具体表现储尿还是排尿问题
  2. 建立时间记录饮水、排尿与漏尿
  3. 结合适当评估区分类型和原因
  4. 选择相应方法不套用统一手法

课堂内容的逻辑限制

“任何漏尿都照同一方法做”“只处理胸腰段就不漏尿”以及否定所有盆底训练的说法，均超出这段展示能够证明的范围。
