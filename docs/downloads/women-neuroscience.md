## 三天课程的整体地图

课程将女性不同生命阶段的身体变化，与感觉、动作、压力和生活体验联系起来。三天内容虽然按现场问答推进，但整理后可沿“认识身体→理解状态→区分具体功能→观察变化”阅读。神经系统是讲者采用的主要视角，身体、关系和医疗背景仍需共同保留。[8.27-01][8.27-02][8.27-03]


### 身体发生什么
月经、孕产、哺乳、手术与年龄阶段可能改变身体和日常需求；每个人的经历与恢复速度不同。


### 本人怎样体验
身体形象、疼痛、疲劳、睡眠、尿意及亲密体验需由本人描述，不用性别概括替代个体信息。


### 实际影响什么
把体验联系到睡觉、进食、行走、排尿、运动与关系中的具体困难，再选择相应主题。


| 主题 | 核心问题 | 三天资料的连接 |

|---|---|---|

| 身体感知与平衡 | 我怎样感到身体的位置、状态和动作？ | 8.27的感觉与演示，连接8.29的头眼、节拍和动作案例。 |

| 压力与睡眠 | 外界要求、个人资源和睡眠表现怎样相互关联？ | 8.27自主神经导入，8.28睡眠/情绪案例，8.29次日反馈。 |

| 月经与内分泌 | 周期、症状与检查如何放在同一时间线上？ | 8.28内分泌框架，联系孕产经历与收尾出血问答。 |

| 消化、胸壁与术后感受 | 痛、胀、外观和组织变化怎样区分？ | 8.27腹部个案，8.28肋间与乳房观察，8.29瘢痕案例。 |

| 盆底、储尿与排尿 | 尿意、漏尿和排空分别发生了什么？ | 8.28未完成的排尿主题，接8.29演示和系统复盘。 |

| 性健康与身体接纳 | 困扰出在哪个环节，本人有哪些需要与意愿？ | 8.29阶段框架、疼痛/感觉问答及身体接纳收尾。 |


逻辑图：生命与生活背景（阶段、经历、支持与需求） → 具体感受（用本人语言说明） → 功能表现（睡眠、动作、排尿等） → 复盘与支持（分项观察，选择相应路径）


整理补充：这张地图表达各主题的阅读关系，不意味着一个脑区或一种手法能统一解释所有女性健康问题。课堂的共同方法是先收集体验，再看功能；每个主题还需要自己的定义、指标和证据。学习可先从最相关的两三个问题入手，再补齐概念。[8.27-01]


复习与应用：先选一个真实学习目标，例如“区分尿急和漏尿”或“看懂睡眠案例”。沿地图找概念、案例和复盘表，避免被现场顺序牵着走。

## 身体感知：输入、体验与功能的区别

闭眼身体形象、镜像观察、轻触与平衡练习，贯穿了三天课程。理解这些演示，需要同时记录感觉来源、观察条件和本人反馈。身体形象模糊、漂浮或左右不同，属于当时的体验，不是自动对应某种病变的诊断图。[8.27-10][8.27-11][8.27-12]


### 外部与接触信息
视觉、听觉、触觉等帮助认识环境与身体。镜像和手机影像改变了可获得的信息。


### 位置与运动信息
本体感觉与前庭相关信息参与姿势和动作；课堂把它们与稳定、身体位置感联系起来。[8.28-09]


### 内部状态体验
内感知（interoception）关注内部状态的感受。胀感、心跳感和尿意要与实际器官功能分开记录。[8.27-24]


| 概念或现象 | 如何理解 | 记录要点 |

|---|---|---|

| 触觉与本体感觉 | 皮肤接触信息与身体位置/运动信息各有侧重 | 力量、接触感和位置感不能互相替代。[8.28-09] |

| 身体意象/身体感受 | 对身体形状、边界和清晰程度的主观报告 | 保留本人比喻，不把“香蕉形”“漂浮”变成疾病名称。[8.27-11][8.27-12] |

| 视觉反馈 | 观看自己的影像或动作，可能改变注意与体验 | 注明镜像、睁闭眼及姿势条件。[8.27-03][8.27-10] |

| 姿势与支撑 | 坐姿、仰卧、脚落地与被支持时的体验可不同 | 先对齐条件，再比较分数。[8.27-10][8.27-11] |

| 痛与不适 | 是真实的个人体验，不能被“脑参与”否定 | 与功能、情绪和既往伤病分别记录。[8.28-05][E01] |

| 主动与被动表现 | 自己做和他人辅助做的动作条件不同 | 差异提供观察线索，不能单独排除结构问题。[8.29-17] |


逻辑图：输入条件（视觉、接触、姿势与支持） → 本人体验（清晰度、舒适度与症状） → 任务表现（能否完成，如何完成） → 同条件复测（记录变化及不确定性）


整理补充：一个人“感觉身体更完整”，并不直接意味着肌力增加、病灶消失或睡眠已改善。这些结果需要各自测量。把“体验—功能—结构”画成三列，能避免用最容易得到的主观反馈替代最想证明的临床结果。


复习与应用：把“感觉好多了”改成具体描述：哪一部位、哪一种感觉、什么姿势下发生变化；再单独记录对应动作是否改变。

## 压力与睡眠：把笼统困扰拆成具体模式

课程用“挑战与资源”理解压力，也讨论活动与休息的切换。这个视角有助于盘点负荷、休息和支持，但不能把现实伤害或关系问题归咎于本人身体差。睡眠则需要独立记录入睡、夜醒、睡眠机会和白天影响。[8.27-08][8.27-09][8.28-10][8.28-11]


### 外界要求
学习难度、工作节奏、家庭期待及关系处境。发生过的伤害和持续压力不能被一个身体解释抹去。


### 可用资源
休息、能力、支持、选择空间和既往经验。课程中的“个人资源”可扩展为环境与社会支持。


### 当下反应
紧张、疲劳、手汗、身体感受与睡眠分别记，不从一种反应推断全部激素或脑区状态。


| 表现或主题 | 值得问清什么 | 与课堂材料的联系 |

|---|---|---|

| 难入睡 | 是否有足够睡眠机会，何时上床，多久入睡 | 与主动玩手机到很晚分开。[8.28-10] |

| 反复醒/睡得浅 | 夜醒次数、清醒多久、能否再睡、环境与饮品 | “一晚都醒着”是主观睡感，不能直接算出睡眠时长。[8.28-10] |

| 学习后疲劳 | 内容太陌生、难度过高，还是连续信息过量 | 调整学习段落与复盘节奏，不直接解释为脑供血不足。[8.27-08] |

| 事件引发情绪 | 针对什么事件，当前感觉与本人意愿是什么 | 身体舒服与事件影响减轻不是同一个结果。[8.28-06][8.28-07] |

| 声音不适 | 声音类型、强度、触发症状及是否出现耳痛 | 有耐受改变，也有负面反馈，不能只记正向结果。[8.28-12][8.28-13] |

| 次日反馈 | 实际睡眠表现与白天状态，有无其他变化 | 8.29有人自述昨夜睡得较好，未形成可归因的长期随访。[8.29-01] |


逻辑图：明确困难（入睡、夜醒或主动延迟） → 补充背景（作息、饮品、环境与支持） → 分别观察（睡眠、情绪、身体体验） → 追踪变化（次日与之后，保留其他因素）


整理补充：课堂在操作后预测“今晚会睡好”，只是一项待验证预期；只有实际夜间记录才能回答。即使次日有人说睡得好，也不能将多人零散反馈拼成同一个案的完整结果，更不能宣称创伤或抑郁已被现场解决。[8.28-13][8.28-20][8.29-01]


复习与应用：复盘时分开写三句话：“当时身体如何”“对事件的感受如何”“当晚睡眠如何”。若某项没有资料，保留为空。

## 月经与内分泌：用时间线读懂变化

内分泌部分的核心是分清调节层次与不同通路：下丘脑、垂体与相应靶腺之间存在信号和反馈关系；压力、生殖与甲状腺话题不能画成同一条单向路线。具体问题仍需回到周期、症状、检查和用药背景。[8.28-01][8.28-02][8.28-03]


### 调节轴分开看
课程讨论下丘脑—垂体—肾上腺与下丘脑—垂体—卵巢两条主线。可以相互影响，但承担不同功能。


### 周期按本人记录
记录出血首日、间隔、持续天数、量与痛感，比较本人以往模式。28天不是人人必须达到的标准。[E06]


### 检查带背景读
保留实际报告、单位、参考范围、周期时点和用药信息；不凭一个数值或一句“有月经”下结论。


| 主题 | 整合后的理解 | 需要保留的信息 |

|---|---|---|

| 周期变化 | 月经是一个时间过程；一次提前或推迟不能说明唯一病因 | 实际日期、连续趋势、疼痛、经量与生活影响。[8.28-02] |

| 压力与生活 | 可与周期一同观察，但不能用安全感统一解释所有变化 | 工作、休息、身体状态及其他同期变化。[8.28-03][8.28-04] |

| 多囊相关话题 | 经期稀发、多毛等是需要进一步了解的线索 | 诊断依据和其他可能原因，不以爱吃甜食代替评估。[8.28-02] |

| 甲状腺话题 | TSH、T3、T4及抗体各有含义，不能共用一个阈值 | 具体检验项目、单位、参考范围和既往结果。[8.28-03] |

| 备孕、手术与内膜 | 结构、激素、症状与周期阶段分开理解 | 原始超声、手术资料、病史与检查时点。[8.28-03][8.28-04] |

| 持续出血与节育环 | 收尾问答是独立健康问题，不能统一归为神经感觉 | 出血模式、器具型号/使用时间及专业评估需求。[8.29-23] |


逻辑图：记录日期与症状（先得到真实时间线） → 比较个人模式（看变化而非单一标准） → 加入检查背景（时点、单位、用药） → 提出具体问题（交给相应评估路径）


整理补充：月经记录的价值，是把“最近不正常”变成可以讨论的趋势。一般信息中，NHS列出常见成人周期21–35天，但个人阶段与变化仍需结合理解；日历也不能保证排卵或避孕安全。本笔记不沿用课堂固定受孕日或“血量越多越好”的说法。[8.28-01][8.28-02][E06]


复习与应用：复习图可画成三条并列线：周期日期、身体症状、生活与检查事件。线之间的重合提示值得问的问题，并不自动证明因果。

## 感觉与动作演示：按目的理解不同方法

三天演示可以按观察目的分组：稳定反应、面部触觉与转头、全身开合配合、头眼配合、镜像及手指节拍。下面整理的是各类演示的意图和反馈维度；动作名称、成人反射判定及部分术语尚有不确定处，不补成独立操作程序。


### 先看目的
想观察稳定性、触觉反应、动作配合，还是对身体的感受？目的不同，不能共用一个“有效”指标。


### 再看条件
姿势、视线、支撑、主动/被动、辅助者及节奏，都会改变任务本身。


### 最后看耐受
能完成多少、是否害怕、疲劳、疼痛或头晕，都属于结果，而非必须熬过的过程。


| 课堂类别 | 希望观察什么 | 应怎样读反馈 |

|---|---|---|

| 前庭相关演示 | 接受重心变化时的稳定与身体感受 | 先看基础能否完成；向前或向后倒不能直接诊断病因。[8.27-13][8.27-15] |

| 觅食反射相关 | 面部触觉反应及转头体验 | 痒、抽动或脸手差异不是已经验证的成人诊断标准。[8.27-16][8.27-17][8.27-20] |

| 惊吓/Moro相关 | 头、眼与全身开合的配合 | 名称具体所指待核；受痛与支持条件影响，保留未完成与加重。[8.27-18][8.27-19][8.27-20] |

| 头眼配合 | 注视、头部运动与原有活动表现 | 腰部轻松、坐骨仍不适、眼酸疲劳分别写。[8.29-15][8.29-16] |

| 镜像与分级动作 | 身体体验、动作信心与尝试能力 | 多种反馈同时出现，不能单独归因一种技术。[8.29-18][8.29-22] |

| 手指节拍 | 节律完成、注意与身体感受 | 约94拍为课堂设置；顺序前后有变化，疲劳/手抖/烦躁也需记录。[8.29-20][8.29-21][8.29-23] |


逻辑图：明确观察目标（先定义何为变化） → 选择可完成条件（支持与挑战匹配） → 记录全部反馈（包含无效和新不适） → 回到原问题（而非只检查动作次数）


整理补充：分级的逻辑是“先能舒适完成，再讨论增加要求”。它不等于统一次数、速度或固定器械。儿童与成人的目标及条件不同；下颌、言语和成人反射问题不能仅因名称相近就套用另一门课的动作。[8.27-21][8.27-22][8.27-23] 平衡障碍也可能涉及不同原因，需要个体化评估。[E04]


复习与应用：为一项演示写出四个词：目的、条件、反馈、缺口。若无法写清条件，就把它作为回看现场视频的线索，而不作为照做教程。

## 消化、胸壁与瘢痕：分开感受、外观和功能

这组主题的共同问题是：本人感觉到的痛、胀、凉、紧，与组织结构或器官功能是什么关系？课程提供了腹部接触、肋间区域、乳房外观和术后瘢痕的现场观察。把指标分开，可以保留案例价值，同时避免用颜色或一次压痛变化替代功能判断。[8.27-24][8.28-16][8.28-17][8.29-03]


### 症状层
“胀”可能指胀感、可见腹围变化或反复嗳气；“胃痛”先具体为上腹哪里、何时不适。


### 外观层
颜色、大小、温度感受灯光、角度、接触与身体阶段影响；描述变化前先固定条件。


### 病史与功能层
食物反应、既往检查、手术及用药各有时间线。感受变化不能独立证明器官恢复或病变消失。


| 主题 | 整合后的记录方法 | 课程提示与局限 |

|---|---|---|

| 腹胀与嗳气 | 分开胀感、嗳气、排气、排便；写明持续时间和进食关联 | 8.27腹部个案约10分降到5–6分，但姿势、支持和操作多次改变。[8.27-24][8.27-25] |

| 冷饮或食物后不适 | 记录具体食物、温度、量、出现时间及其他因素 | 不能因别人耐受就否认本人，也不通过强行刺激验证理论。[8.28-14][8.28-15] |

| 肋缘/肋间触碰 | 位置、施力者、诱发反应与即时变化分项记 | 现场有痛、凉、恶心，也有减轻和变胀；这些不能互相覆盖。[8.28-16][8.28-19][8.28-21] |

| 乳房与乳晕 | 将颜色、大小、舒适度分别记录，控制灯光和角度 | 外观不能推断性经历、品行或内脏供血；本人意愿优先。[8.28-17][8.28-18] |

| 旧瘢痕与术后不适 | 手术背景→症状出现→当前触感/动作→后续变化 | 红白颜色不能独立判断炎症；先后关系不等于因果。[8.29-03][8.29-22] |

| 食欲、产品与持续性 | 记录实际进食、同步使用的产品及随访 | 食欲增加自述、复购和产品说明不能充当普遍疗效数据。[8.28-18][8.28-21] |


逻辑图：具体描述（位置、感觉、诱因与时间） → 核对病史（检查、手术和用药） → 固定比较条件（姿势、接触与环境） → 分层解释（体验、外观、功能分别看）


整理补充：若一个案例在不同姿势下反复评分，应画“条件与反馈表”，而非仅画一条不断下降的曲线。前者忠实保留信息，后者可能让读者误以为所有数字来自同一标准测试。腹部和乳房观察也不能直接验证讲者关于肋间神经、迷走神经与全部内脏功能的模型。[8.28-17]


复习与应用：当看到“颜色浅了”“不那么胀了”“压着不痛了”时，先明确它属于哪一层指标，再问还需要什么资料才能回答真正的健康问题。

## 盆底与排尿：三个问题，一条协调链

8.28末尾开始的排尿主题，在8.29继续演示并系统复盘。主线可以整理为“储存→感知充盈→选择时机→协调排出”。尿意、控尿和排空是相关而不同的结果；一个环节的主观变化，不能替代其他环节的测量。[8.28-22][8.28-23][8.28-24][8.29-13]


### 尿意
此刻想不想排尿、感觉多强。与饮水、上次排尿和环境有关，不等于实际尿量。


### 控尿
是否发生不自主漏出，发生在咳嗽/跳跃还是强烈急迫感时。需要具体次数和情境。


### 排空
能否顺利启动、尿流如何、是否排尽。主观不尽感与实际残余尿是不同信息。


| 表现 | 重点记录 | 课堂结果应怎样理解 |

|---|---|---|

| 咳嗽或跳跃漏尿 | 活动情境、是否真的漏出、影响程度 | 这是任务相关表现，不能用操作后尿意下降替代。[8.29-02] |

| 尿急/尿频 | 急迫程度、频次、间隔、是否伴漏出 | 8.28有约8–9分降到2–3分的口述，仅说明当时尿意变化。[8.28-23] |

| 尿不尽/排尿困难 | 启动、尿流、排尿后感觉及相关检查 | 不能当场排尿时，排空结果应记“尚未测到”。[8.29-02] |

| 术后尿意减弱 | 手术类型/时间、充盈感、排尿习惯、检查 | 不能仅从旧疤或触感推定病因。[8.29-07] |

| 下坠或肛周不适 | 坠胀、痒、痛、组织检查与病史分别写 | 感觉收紧不能证明痔疮、脱垂等结构问题消失。[8.29-03][8.29-12] |

| 训练与处理选择 | 明确类型、目标、耐受与后续指标 | 整体看待感觉和协调，并不否定盆底肌训练的价值。[8.29-01][8.29-13][E03] |


逻辑图：储存（膀胱充盈与控尿） → 感知（记录尿意和情境） → 协调（选择时机并排出） → 复盘（尿意、漏尿、排空各自评价）


整理补充：这条协调链是功能示意，不是从体表按到某个脊髓节段的路线图。皮肤、椎骨、神经根和脊髓节段不可混为一谈。现有课堂没有连续漏尿次数、残余尿或长期对照资料，因而不能把“一次不想尿了”写成尿失禁已治愈。[8.28-23][8.29-08] NIDDK的治疗说明强调按类型与原因选择方案。[E03]


复习与应用：一份排尿观察表可设：时间、饮水、尿意强度、是否排尿、是否漏出、触发情境、不尽感。它帮助描述问题；具体检测及处理仍按需要进行。

## 性健康与身体接纳：以本人体验为中心

课程以兴奋、持续、高潮、消退四阶段组织性健康内容，并连接触觉、局部感觉和身体状态。阶段图有助于表达困扰，但不是人人必须完成的固定顺序或时长。健康判断应围绕本人是否困扰、是否疼痛、是否自愿，以及身体和关系背景。[8.29-04][8.29-06][E05]


### 意愿与需求
欲望和频率可以不同。尊重拒绝、允许改变决定；关系中的强迫不能被解释成被迫者体能或神经有问题。


### 舒适与功能
疼痛、干涩、胀感和触觉分别描述；某种偏好、较长准备时间或不愿触碰不自动意味着疾病。


### 接纳与支持
身体观察和镜像可以作为课程体验来理解，须尊重本人选择。外观不满意不能被写成疾病的责任。


| 观察维度 | 有帮助的问题 | 需要避免的简化 |

|---|---|---|

| 欲望与兴奋 | 在什么情境下愿意或不愿意？是否因此困扰？ | 不以固定分钟数或频率判断神经损伤。[8.29-04][8.29-06] |

| 润滑、疼痛与舒适 | 痛在哪里、何时出现，是否与手术、阶段或药物有关？ | 不能把干涩与疼痛统一归因于心肺弱。[8.29-11][8.29-12] |

| 高潮与恢复 | 本人如何描述，有无满意或不适，期待是什么？ | 不用最大心率、统一时长或某一种表现打分。[8.29-04][8.29-10] |

| 局部触觉 | 痛、痒、坠胀、舒适和无明显感觉分开 | 没有愉悦不等于某条神经损坏；不同人的结果不混算。[8.29-05][8.29-09] |

| 关系与同意 | 双方的愿望、拒绝与安全是否受到尊重？ | 次数不同不决定谁有病，也不产生配合义务。[8.29-07] |

| 术后与身体形象 | 手术背景、动作、感觉、本人愿意面对什么？ | 不强迫观看或触摸，不把自我接纳写成治疗疾病的必要条件。[8.29-22][8.29-23] |


逻辑图：说明本人困扰（不预设正常答案） → 定位发生环节（欲望、舒适、疼痛等） → 理解背景（身体、药物、关系与经历） → 选择支持（尊重意愿，按问题评估）


外部核对：ACOG将欲望、唤起、高潮、性疼痛及药物相关问题分别讨论，也指出这些问题可能重叠。欲望可能在互动开始后出现，身体、情绪、关系和生活状态均可参与。[E05] 课堂的神经名称和脑影像可作为查证索引，但原图、论文与节段有缺失，不能直接推出外部手法的疗效。[8.29-05][8.29-10]


复习与应用：复习时用中性语言重述一个困扰，说明本人希望怎样改变；再区分哪些是体验、哪些是讲者推测、哪些仍需其他资料。

## 跨文件案例：看见连续过程与不同结局

案例的完整性来自清楚的过程与限制，而非只保留最后一句“好了”。下面将三天中的关键案例重新串联，保留改善、未改善、条件变化及随访缺口；个案均作匿名主题索引，不保留身份或可识别的私人细节。


### 不跨人拼接
相邻段落可能换了参与者。某人睡得好，不能补作另一位情绪个案的随访。


### 不跨指标替代
身体清晰度、自信、疼痛和对某事件的情绪，是不同分数。


### 不跨时间承诺
现场舒服、次日自述、稳定长期效果属于不同证据层级。


| 连续案例 | 过程与实际反馈 | 最值得学到什么 |

|---|---|---|

| 多症状个案 | 紧张、腹胀与肩部不适分别记录；初段腹胀减轻而肩部未明确改变，后段再有改善自述。[8.27-17][8.27-18] | 分项复测比一个总体“有效”更清楚。 |

| 尾骨痛与原有神经痛 | 练习后曾加重；调整支持后部分尾骨反馈减轻，当天收尾仍有不适。[8.27-18][8.27-19][8.27-25][8.27-26] | 原有胸背神经痛没有明确改善证据，不能由尾骨反馈代替。 |

| 持续腹部不适 | 从时间线、用药与胀感入手；多种姿势/支持后评分下降。[8.27-24][8.27-25] | 条件改变需要随分数保留，不画伪精确疗效曲线。 |

| 情绪与身体案例 | 清晰度约2→6，自信约4–5→7；部分身体不适减轻，对事件的情绪仍复杂。[8.28-06][8.28-07] | 身体变舒服不等于创伤或关系问题已解决。 |

| 消化练习反馈 | 有即时减轻，也出现更胀、更硬和反复操作后的不适。[8.28-16][8.28-19][8.28-21] | 负面结果进入同一张表，不能都归为操作不到位。 |

| 长期步态困扰 | 先核对诊断来源，再比较主动/被动，加入分级动作、镜像与注意反馈。[8.29-17][8.29-18][8.29-19] | 多种方法同时出现，且缺后续功能评价，不能确定单独疗效。 |

| 头眼与节拍练习 | 有腰部轻松、踏实感，也有残余不适、眼酸、手抖与烦躁。[8.29-16][8.29-21] | 完成程度和耐受均重要，不能把疲劳直接解释为脑区被修复。 |


逻辑图：从主诉出发（分清谁与什么问题） → 串联各文件（保留每阶段条件） → 并列所有结果（改善、未改、加重） → 写明结论上限（持续性与机制未知）


整理补充：案例表可以向两边展开。向前补病史、目标和基线，向后补生活功能、持续性及后续求助。当前资料主要停留在现场，因此完整记录的表现是明确留出缺口，而不是用课堂预测填满缺口。


复习与应用：试着为一例写出“本次观察支持什么”和“本次观察尚不能支持什么”。两句话都应能回到具体文件。

## 把课程串成可复习、可讨论的知识体系

学习的落点是能解释一个问题、说清一份观察，并知道哪些内容还需要查证。把运动、身体感受和具体健康主题连接起来时，保留各自的指标和适用条件，避免形成“所有问题都归于同一神经机制”的总公式。[8.27-01][8.29-12][8.29-13]


### 概念复习
用一句话定义术语，再给一个案例；遇到定义不清或原图缺失，回到出处而不补造。


### 案例复盘
按“问题—条件—反馈—缺口”整理；将不适和未改善与改善放在一起。


### 应用讨论
先明确目标，再谈任务和负荷；区分课程学习、一般活动与需要专门评估的问题。


| 综合主题 | 可以保留的理解 | 需要校正或继续查证 |

|---|---|---|

| 运动安排 | 类型、强度、时长、频率和恢复要具体。[8.27-05][8.27-06] | 一般指南与4×4等高强度框架分开；不要求人人冲击最大心率。[8.29-20][E02][E09] |

| 平衡与心率 | 支撑面、姿势、视线和任务难度都影响负荷。[8.29-14] | 穿戴读数与真实不适分别核查，不直接诊断前庭病变。 |

| 饮食限制 | 询问具体食物、症状和时间关联。[8.27-14] | 不从失衡方向、皮肤或性格要求普遍戒食；食物IgG不能诊断过敏。[E07] |

| 补充剂与抗衰 | 保留为待查话题，不组成统一保健清单。[8.29-11][8.29-19] | 不能从个人经历、价格或简单机制解释推导普遍效果。 |

| 产品与手法 | 记录成分/参数是否明确、过程和反馈。[8.28-21][8.29-07] | 原文缺少独立比较资料，不能以用量不足解释全部失败。 |

| 身体接纳与差异 | 尊重本人体验、正常外观差异及拒绝接触的权利。[8.28-18][8.29-23] | 不把疾病、亲密偏好或情绪困扰归责于“不爱自己”。 |

| 片段与转写 | 课间、短答、指代不清的内容保留索引。[8.27-07][8.27-23][8.28-20] | 没有完整信息时不扩写新理论，也不编造时间戳。 |


逻辑图：选一个问题（清楚表达学习目标） → 找对应概念（用表格说明差别） → 连读一个案例（保留过程与条件） → 形成复盘记录（写出来源和待解问题）


自测清单：①区分触觉、本体感觉、内感知与身体意象；②区分睡眠困难的不同模式；③说明月经记录为何要带时间线；④区分尿意、漏尿与排空；⑤解释感受改善为何不等于组织修复；⑥说清同意与个人意愿在课堂观察中的位置。


复习与应用：最后形成一页个人学习图：中心写当前问题，四周依次放概念、案例、可观察指标和待查证问题。每一项附文件编号，下一次复习便能从问题回到具体材料。

## 外部核对资料（2026-10-30）

- [E01] [IASP｜疼痛定义与术语](https://www.iasp-pain.org/resources/terminology/)：疼痛是个人体验，不能仅从组织或神经信号推断。

- [E02] [WHO｜身体活动与久坐指南](https://www.who.int/europe/publications/i/item/9789240014886)：一般成人有氧及肌力活动建议；不等于个体运动处方。

- [E03] [NIDDK｜尿失禁的治疗](https://www.niddk.nih.gov/health-information/urologic-diseases/bladder-control-problems/treatment)：按类型及原因选择处理，盆底肌训练是治疗选项之一。

- [E04] [NIDCD｜平衡障碍](https://www.nidcd.nih.gov/health/balance-disorders)：平衡涉及多个系统，评估和康复应个体化。

- [E05] [ACOG｜女性性健康](https://www.acog.org/womens-health/faqs/your-sexual-health)：欲望、唤起、高潮及疼痛问题可相互重叠，并受多种因素影响。

- [E06] [NHS｜月经](https://www.nhs.uk/conditions/periods/)：周期存在个体差异，变化需联系本人模式和相关症状。

- [E07] [AAAAI｜食物IgG检测](https://www.aaaai.org/tools-for-the-public/conditions-library/allergies/igg-food-test)：食物IgG不能据以诊断食物过敏或不耐受。

- [E08] [NIDDK｜乳糜泻诊断](https://www.niddk.nih.gov/health-information/digestive-diseases/celiac-disease/diagnosis)：诊断结合病史与检查；先自行去除麸质可能影响结果。

- [E09] [NTNU CERG｜运动建议与4×4间歇](https://www.ntnu.edu/cerg/advice)：相关4×4框架采用85%至95%最大心率，不要求达到100%。
